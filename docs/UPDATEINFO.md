## 0.8.0

### XCPC Tracker

- 新增独立 XCPC Tracker 页面，并接入现有侧边栏、主题、字号、密度和 QOJ 同步流程。
- 比赛默认按时间倒序排列，支持 ICPC、CCPC、省赛及其他系列切换，以及阶段、年份、赛站和完成进度筛选。
- 比赛、日期与进度固定在表格左侧，横向滚动只影响题目区域。
- 默认使用无题名紧凑矩阵，一屏显示 A–M；可切换显示题名与正式队通过数。
- 支持比赛全称与简称切换，并分别记忆题名、难度颜色和名称模式偏好。
- 目录从 QOJ 官方 ICPC、CCPC、省赛/邀请赛分类实时抓取并本地缓存；点击比赛或题块可直接打开 QOJ 页面，个人 AC 状态来自本地 QOJ 同步记录。
- 公开榜单评级字段预留为可选数据；没有可靠榜单匹配时不伪造金银铜铁颜色。

### 工程

- XCPC 赛事模型与 QOJ 分类抓取适配层独立于页面，后续可接入 RankLand / XCPCIO 的公开榜单匹配。
- 版本统一更新为 0.8.0，现有 GitHub Actions 可直接执行普通三平台构建或 `v0.8.0` 签名 Draft Release。

## 0.7.1

### 体验

- 新增介于亮色和暗色之间的灰色主题，沿用现有页面结构、组件比例和平台配色。
- 难度分布新增“未评级”，点击后可查看能够取得明细的题目；只有未评级题目的日期会在难度砖中以独立纹理显示。
- 默认在启动后后台增量同步全部已配置平台；无新增且全部成功时保持安静，可在设置中关闭。

### 更新

- 默认在启动后后台检查更新，发现新版本时提供立即更新、稍后提醒和跳过当前版本。
- 接入 Tauri 签名更新，显示下载进度；失败时保留当前版本并提供 GitHub Release 手动下载入口。
- 标签构建自动发布 `latest.json` 和 updater 签名产物；面向新用户的安装包仍仅为 EXE、Universal DMG 与 AppImage。
- 修复数据源页面右上角“同步全部”按钮无法触发同步的问题。
- 修复已有 Draft Release 时发布工作流可能返回 404 的问题。
- 三端安装包由发布流程统一添加 `Windows`、`MacOS`、`Linux` 后缀，并在改名后生成更新清单，避免自动更新下载地址失效。

## 0.6.0

### 功能

- Rating 曲线点支持悬停或键盘聚焦查看比赛名称、日期、排名和 Rating 变化，点击后打开对应比赛。
- 难度分布柱形支持点击，并在原有抽屉样式中显示该难度的全部去重题目；汇总源缺少逐题数据时明确提示。
- 设置新增版本化 JSON 个人信息导出；默认排除 Cookie / Session，可在敏感信息警告后选择完整导出，始终排除个性化设置和训练记录。
- 导出页统一收纳活动砖图片与个人信息两类导出。

### 界面与发布

- Rating 用户名放大到接近当前 Rating 数字的层级，其他既有卡片与页面布局保持不变。
- 关于页标识由 `OI` 修正为 `OJI`。
- MacOS 社区构建增加临时签名完整性检查，并补充 Gatekeeper 隔离标记的可信来源处理说明。
- 工作流最终生成 `OJ-Insight-All-Platforms.zip`，根目录只包含 `.exe`、`.dmg` 与 `.AppImage`。
- 应用版本统一更新为 0.6.0，发布命名中的 `macOS` 统一为 `MacOS`。

## 0.5.1

### 修复

- 修复字号切换后文字、图标和难度柱图错位或被裁切的问题。
- 左上角 Logo 恢复为固定比例的圆角正方形。
- 洛谷只能取得可信聚合、题量或难度数据时标记为“部分成功”，同步全部不再计入失败平台。
- macOS CI 改为 Universal 构建，同时包含 Intel 与 Apple Silicon，并明确最低支持 macOS 11。
- 修复亮色模式下关于页 OI 标志、数据源危险操作区、导出预览和活动砖仍显示暗色背景的问题。

### 界面

- 活动砖使用同一基色的透明度分级，并提高亮色模式辨识度。
- 难度分布保留各 OJ 自身分级边界和色相；Codeforces 保留每 100 rating 一档，AtCoder 只显示数值区间。
- 难度图所有柱子使用一致宽度，按容器动态调整间距，完整居中显示；解题数固定在对应柱顶。
- Rating 用户名按平台段位色显示，当前 Rating 与历史最高并列突出，辅助统计改为最近变化、近 90 天净变化和 Rated 场次。

### 工程

- 拆分设置、数据源、导出和关于页面文件。
- 合并三平台构建文档，增加版本一致性检查，统一应用版本为 0.5.1。
