# 更新记录

## 开发中

### Training System

- 新增跨 OJ Static Problem Set，可排序题目并设置角色、备注、标签和标签可见性。
- 题单支持本地 JSON Manifest 导入与导出，Fork 后保留来源标识。
- 新增轻松、均衡和压力三种训练模式；目标完成比例作为可调整、待验证的参数保存到每场 Match。
- Match 提供计时、题目进度和结束状态；在原 OJ 提交并同步后，按 canonical problem identity 自动更新 AC。
- 候选过滤严格排除本地已做题、interactive、output-only 和明确不适合日常训练的题目。
- 新增 Training Pack，包含 `START-HERE.md`、`PROFILE.md`、`TRAINING-STATE.md`、`CONSTRAINTS.md`、`CANDIDATES.json` 和 Match Manifest schema。
- 支持导入结构化 Match Manifest；导入时再次执行题目标识、重复项、角色、适配性和已做题校验。

### 工程结构

- 数据库、XCPC 和前端样式按职责拆分，应用级账号、快照、同步、关注和更新逻辑进入独立 hooks。
- 更新架构文档并统一前端页面导航类型。

## 0.9.2

### 比赛复盘

- 新增统一的比赛复盘入口，可选择账号并输入 AtCoder 比赛 ID 或完整链接。
- 收集比赛信息、题目、完整提交时间线和可获取的历次代码；暂未稳定接入的平台不再提前展示。
- 复盘包固定为四份 Markdown 文档；上传给大模型后无需额外说明，或只需说“开始复盘”。
- 正式比赛与赛后补题分开标记；代码、题面或排名缺失时明确报告，不伪造完整数据。
- Cookie、Session、本机路径等敏感信息不会写入复盘包，所有整理与打包均在本地完成。

### 数据与总览

- “今日进度”新增当天完成题目、题目难度、提交信息和当天已结束比赛的赛况；比赛结束并同步后更新过题、排名与 Rating 变化。
- Rating 多账号图会记住当前选择，并统一 AtCoder Rating 的展示名称。
- 牛客普通题 Rating 与每日一题独立难度分开展示，修正 Rating 文本断行和柱形间距。
- QOJ 题目难度颜色与 ICPC / CCPC Tracker 对齐，并适配深色、浅色和灰色主题。
- 各 OJ 页面与总览增加 API / Cookie 配置入口；不需要凭据的平台不显示入口。

### ICPC / CCPC Tracker

- 新增金牌题、银牌题、铜牌题和铁牌题多选筛选；筛选后只显示包含所选颜色题目的比赛和对应题块。
- 筛选后的比赛进度、完成题数和题目总数同步按当前可见颜色统计。
- 视图开关改为原生可交互的无障碍 Switch，筛选项拥有可靠的原生点击区域，避免 WebKit 点击超时。

### 工程与兼容性

- 数据请求统一使用 HTTP 流程，避免长连接反复重连影响使用。
- 应用版本统一更新为 0.9.2。

## 0.9.1

### 日常体验

- 在总览的“今日进度”中增加每日打卡；每天可主动记录一次，刷新或重启应用后仍会保留。
- 显示累计打卡天数，不设置连续、断签或补签机制，保持轻松的使用体验。
- 打卡完成后展示一条简短的正反馈，并适配现有深色、浅色与灰色主题。
- 打卡反馈在刷新后继续保留，并补充轻量动效；固定右侧各 OJ 今日卡片高度，避免内容被拉伸。
- 同步后若某个 OJ 的做题总量增长，会在总量旁以随机位置短暂显示 `+N`。
- 修正 Codeforces 元数据回填被反复当成全量新增的问题，并让重复的牛客 Rating 记录安全去重。
- 牛客 Tracker 为已完成或已匹配的每日题补充页面公开难度；QOJ 同步登录后个人页的当前 Rating。
- 洛谷页面不再显示不可用的 Rating 与最近 AC；移除完成验收后的动效测试按钮。
- “增量 / 重建”改为“同步最新记录 / 重新同步全部”，并补充适用场景说明。
- 今日进度新增无断签压力的积累反馈：展示已走过的题量、小里程碑和允许休息的提示。
- 能力画像改为“能力证据分”：结合难度、近期程度和同类题目的递减收益，不再直接把做题数量当作能力值。
- 提高浅色、灰色主题活动砖层级对比，并重做浅色主题 ICPC / CCPC 银题、铁题灰阶。
- ICPC / CCPC Tracker 新增默认关闭的知识标签开关，避免提前剧透题型。
- 导出页右侧改为简化的布局示意，明确实际图片会使用真实数据生成。

### 工程

- 增加每日打卡持久化、标签开关、能力证据分与导出预览回归测试。
- 应用版本统一更新为 0.9.1。

## 0.8.0

### ICPC / CCPC Tracker

- 新增独立 ICPC / CCPC Tracker 页面，并接入现有侧边栏、主题、字号、密度和 QOJ 同步流程。
- 比赛默认按时间倒序排列，支持 ICPC、CCPC、省赛及其他系列切换，以及阶段、年份、赛站和完成进度筛选。

- 公开榜单评级字段预留为可选数据；没有可靠榜单匹配时不伪造金银铜铁颜色。

### 工程
